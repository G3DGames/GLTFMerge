Unit glTF.Base

Description

Base classes and exceptions of the glTF 2.0 reader and writer.

TglTFProperty is the abstract base of every glTF object: it loads an object from JSON, checks the properties the schema requires, keeps extensions, extras and non-standard properties so they can be queried, and writes the object back to JSON. TglTFList holds the arrays of glTF objects. Errors are reported with EglTFError and its descendants, which carry the JSON path and, when the text is known, the line of the problem.

JSON values are read and written with the Neon library (https://github.com/paolo-rossi/delphi-neon@). The unit has no VCL or FMX dependencies, so it works on every target. Specification: https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html
