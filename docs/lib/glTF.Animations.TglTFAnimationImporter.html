Unit

glTF.Animations

Declaration

type TglTFAnimationImporter = class(TObject)

Description

Imports the animations of other glTF files into a document, one animation at a time.

Set OnDuplicate, and OnProgress if wanted, then call ImportFiles. Duplicates are found by name, ignoring case, among the model's animations, including those added earlier in the same import. Without an OnDuplicate handler, duplicates keep the old animation. The importer owns the documents it loads; free it after the import. 

Importer := TglTFAnimationImporter.Create(Doc);
try
  Importer.OnDuplicate :=
    procedure(AImporter: TglTFAnimationImporter; ACandidate: TglTFAnimationCandidate;
      AExisting: Integer; var AAction: TglTFDuplicateAction; var ANewName: string)
    begin
      AAction := daRename; // keep both, under the suggested name
    end;
  Importer.ImportFiles(['walk.glb', 'run.glb']);
finally
  Importer.Free;
end;

Public function ImportFiles(const AFileNames: TArray<string>): Integer;

Imports the animations of several .gltf or .glb files.

Each file is loaded and its animations matched and added in turn; see the unit description. A file that cannot be loaded, or has no animations, adds a line to Log and the import goes on. Stops early on an abort. At the end, the data only replaced animations used is removed from the model.

Parameters
AFileNames
The files, in the order their animations are to be added.
Returns

The number of animations added or replaced.

Public function ImportDocument(ASource: TglTFDocument; const AFileName: string): Integer;

Imports the animations of an already loaded document.

Like ImportFiles for one file, including the removal of replaced data at the end.

Public procedure RequestAbort;

Asks the import to stop once the animation being added is finished.

May be called from any thread, typically the main thread while the import runs in a background thread. The remaining animations and files are not imported; those already added stay.
