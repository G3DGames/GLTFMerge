Unit

glTF.Edit

Declaration

type TglTFEdit = class(TObject)

Description

Editing operations on a glTF object tree that keep its indices consistent.

All methods are class methods; there is nothing to create. A Delete method assumes the object it deletes is no longer referred to: use the matching IsUsed method, or DeleteUnusedData, which checks. 

// Drop animation 2 and whatever data only it used
TglTFEdit.DeleteAnimation(Doc.Root, 2, Warnings);

Public class function UsesBufferViewExtension(ARoot: TglTF; out AName: string): Boolean; static;

Tells whether the tree uses an extension that refers to bufferViews or buffers from its own JSON.

These are KHR_draco_mesh_compression, EXT_meshopt_compression and KHR_meshopt_compression. While one is used, bufferViews and buffers must not be deleted, as the extension's indices would then point at the wrong data.

Public class procedure DeleteBufferView(ARoot: TglTF; AIndex: Integer); static;

Deletes a bufferView, cuts its bytes out of its buffer and renumbers the references to the bufferViews after it.

The bytes cut are the view rounded up to 4 bytes, so its padding goes too, or rounded down when another view uses the padding; nothing is cut when another view overlaps it. The views after it in the same buffer move down by the amount cut, which is a multiple of 4 unless the view is at the end of the buffer. The buffer's Data is replaced by a new array, so an array shared with another tree is not changed. Nothing may still refer to the bufferView itself.

Parameters
ARoot
The tree to change.
AIndex
Index in ARoot.BufferViews.
Public class procedure DeleteAccessors(ARoot: TglTF; const AIndices: TArray<Integer>); static;

Deletes several accessors at once and renumbers every reference to the others.

Much faster than deleting them one by one: the references are renumbered in one pass. Nothing may still refer to the accessors deleted. Their bufferViews are left in place.

Parameters
ARoot
The tree to change.
AIndices
Indices in ARoot.Accessors, in any order; repeats and invalid indices are ignored.
Public class procedure DeleteBufferViews(ARoot: TglTF; const AIndices: TArray<Integer>); static;

Deletes several bufferViews at once, cutting their bytes out of their buffers.

The same rules as DeleteBufferView, applied to all of them together: each buffer is rebuilt once, without the bytes cut, and the references to the remaining views are renumbered in one pass. Bytes a remaining view uses are never cut. Nothing may still refer to the views deleted.

Public class function DeleteUnusedData(ARoot: TglTF; const AAccessors: TArray<Integer>; AWarnings: TStrings): Integer; static;

Deletes those of the given accessors that nothing uses any more, then the bufferViews and buffers that only they used.

Only the listed accessors and the bufferViews and buffers they lead to are considered, so data the file never used is left alone. Up to 3 zero bytes of padding left at the end of a buffer that was cut are removed too. A buffer is deleted when its data was cut down to nothing. When the tree uses an extension that would be broken, the step concerned is skipped and a warning added.

Parameters
ARoot
The tree to change.
AAccessors
Indices in ARoot.Accessors that may have become unused; may repeat and may include indices that are still used.
AWarnings
Receives a line for each step skipped; may be nil.
Returns

The number of accessors deleted.

Public class procedure DeleteNodes(ARoot: TglTF; const AIndices: TArray<Integer>; AWarnings: TStrings); static;

Deletes nodes and renumbers every reference to the nodes after them.

The children of a deleted node that stay take its place: in its parent's children, or among the root nodes of the scenes it was in. Animation channels that target a deleted node are removed, and an animation left without channels is deleted with the data only it used. A deleted node that was a skin's "skeleton" leaves that skin without one. The meshes, skins and cameras of the deleted nodes stay; see DeleteUnusedObjects.

Only the glTF 2.0 core references are renumbered; an extension that refers to nodes from its own JSON is not.

Parameters
ARoot
The tree to change.
AIndices
Indices in ARoot.Nodes, in any order; repeats and invalid indices are ignored.
AWarnings
Receives a line for each step skipped; may be nil.
Exceptions raised
EglTFError
A node to delete is a joint of a skin; nothing is changed.
Public class function DeleteUnusedObjects(ARoot: TglTF; const AMeshes, ASkins, AMaterials, AAccessors: TArray<Integer>; AWarnings: TStrings): Integer; static;

Deletes those of the given meshes, skins and materials that nothing uses any more, then everything that only they used.

Works down from the objects given: meshes no node uses, skins no node uses, and materials no primitive uses are deleted; then the textures only the deleted materials used, the images and samplers only those textures used, and the accessors, bufferViews and buffer bytes only all of these used (see DeleteUnusedData). Every reference to the objects that follow is renumbered, texture references in material extensions and image references in texture extensions included. Objects the file never used are left alone, as only what the given objects lead to is considered.

Materials are kept when the tree uses KHR_materials_variants, which refers to them from its own JSON; a warning says so.

Parameters
ARoot
The tree to change.
AMeshes
Indices in ARoot.Meshes that may have become unused.
ASkins
Indices in ARoot.Skins that may have become unused.
AMaterials
Indices in ARoot.Materials that may have become unused.
AAccessors
Further indices in ARoot.Accessors that may have become unused.
AWarnings
Receives a line for each step skipped; may be nil.
Returns

The number of meshes, skins, materials, textures, images and samplers deleted.

Public class procedure RemapTextureRefs(AValue: TJSONValue; const AMap: TFunc<Integer, Integer>); static;

Calls a function for every texture reference in a material's JSON and replaces the index with what it returns.

A texture reference is an object with a numeric "index" under a name ending in "Texture", such as baseColorTexture, or clearcoatTexture inside an extension. The whole value is searched, so references in extensions are found too.

Parameters
AValue
A material, or part of one, as JSON; changed in place.
AMap
Returns the new texture index for an old one; returning the same index leaves it as it is.

Public class function DeleteUnusedImages(ARoot: TglTF; AWarnings: TStrings): Integer; static;

Deletes every material, texture, image and sampler the meshes do not lead to.

The images left are exactly those ImagesInUse reports as needed. Materials no primitive uses go first, then the textures no remaining material uses, then the images and samplers no remaining texture uses, and the bufferViews and buffer bytes only those images used. Every reference to the objects that follow is renumbered. Used on the copy made for a save, so that a saved file holds only the images it needs.
