This item has no description. Showing description inherited from TglTFProperty.ReadChildren.

Loads nested glTF objects, lists and maps; does nothing by default.

Called by LoadFromJSON after the simple values have been read. Free any previously loaded children first, as an object can be loaded more than once.

Returns the object's name in the glTF specification.

Returns

Public function ComponentCount: Integer;

Returns how many components each element has.

Returns

1 for SCALAR, 2 to 4 for VEC2 to VEC4, 4, 9 or 16 for MAT2 to MAT4; 0 for an unknown type.

Public function ComponentByteSize: Integer;

Returns the size in bytes of one component.

Returns

1, 2 or 4; 0 for an unknown component type.

The glTF "bufferView" holding the data; GLTF_UNDEFINED_INDEX when not set.

Without a bufferView every element is zero unless replaced by sparse values.
