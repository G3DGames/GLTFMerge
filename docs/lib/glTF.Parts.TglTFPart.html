Unit

glTF.Parts

Declaration

type TglTFPart = class(TObject)

Description

One skinned mesh found in a part file: a piece that can be put on a model.

Created and owned by TglTFPartLibrary; read-only for its users.

Public function CoveredText(const AOptions: TglTFPartOptions; AMax: Integer = 4): string;

Returns the bones the part covers with their shares, for display.

Parameters
AOptions
Decide the share a bone needs and the bones never covered.
AMax
Most bones listed; the rest are counted.
Returns

For example "foot_l 64%, ball_l 30%"; "none" when it covers no bone.
