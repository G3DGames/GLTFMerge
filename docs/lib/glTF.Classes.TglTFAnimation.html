Public property ExportOnSave: Boolean read FExportOnSave write FExportOnSave;

Whether a save writes this animation.

True by default. When False, TglTFDocument leaves the animation out of the saved file, together with the accessors, bufferViews and buffer bytes only it used; the document itself keeps them. A save choice, not part of the glTF JSON.
