Description

The glTF 2.0 object types, one class per object of the glTF schema.

Property JSON names are given with [NeonProperty] and properties the schema requires with [glTFRequired]. Optional index properties, such as accessor.bufferView or node.mesh, default to GLTF_UNDEFINED_INDEX (-1); every other optional value defaults to the value the specification defines. IsDefined tells whether a value was present in the loaded file.

TglTFBuffer and TglTFImage also carry their binary data and save choices, which are not part of the glTF JSON: Data, SourceFile and, for images, Embed.

Description

Types

TglTFAccessorType = (...);

The accessor "type" as an enumeration.

The schema allows other strings for extensions; those map to atUnknown.

Values
  • atUnknown: Any other string.
  • atScalar: "SCALAR": one component.
  • atVec2: "VEC2": two components.
  • atVec3: "VEC3": three components.
  • atVec4: "VEC4": four components.
  • atMat2: "MAT2": a 2 by 2 matrix.
  • atMat3: "MAT3": a 3 by 3 matrix.
  • atMat4: "MAT4": a 4 by 4 matrix.
TglTFAlphaMode = (...);

The material "alphaMode" as an enumeration.

Values
  • amUnknown: Any other string.
  • amOpaque: "OPAQUE": alpha is ignored.
  • amMask: "MASK": fully opaque or fully transparent, by alphaCutoff.
  • amBlend: "BLEND": alpha blends with the background.
TglTFAnimationPath = (...);

The animation target "path" as an enumeration.

Values
  • apUnknown: Any other string.
  • apTranslation: "translation".
  • apRotation: "rotation".
  • apScale: "scale".
  • apWeights: "weights": morph target weights.
TglTFInterpolation = (...);

The animation sampler "interpolation" as an enumeration.

Values
  • ipUnknown: Any other string.
  • ipLinear: "LINEAR".
  • ipStep: "STEP": values are held until the next key frame.
  • ipCubicSpline: "CUBICSPLINE": cubic spline with tangents.
TglTFCameraType = (...);

The camera "type" as an enumeration.

Values
  • ctUnknown: Any other string.
  • ctPerspective: "perspective".
  • ctOrthographic: "orthographic".
TglTFAttributeMap = TDictionary<string, Integer>;

Maps attribute semantics to accessor indices.

Keys are names such as POSITION, NORMAL or TEXCOORD_0; values are indices in TglTF.Accessors.
