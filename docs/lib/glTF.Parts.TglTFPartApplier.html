glTF.Parts

Declaration

type TglTFPartApplier = class(TObject)

Description

Puts parts on a model and takes them off again.

Create one per model and keep it as long as the model is open: it remembers the body's triangles from before the first change, so that hidden triangles can come back. Create a new one when another model is loaded. See the unit description for what Apply does. 

Applier := TglTFPartApplier.Create(Doc);
Applier.Apply([Library[0], Library[3]], TglTFPartOptions.Default);

Public function Apply(const AParts: TArray<TglTFPart>; const AOptions: TglTFPartOptions): Integer;

Puts parts on the model.

The parts are put on in turn, each taking off the pieces it replaces, so of two parts that cover the same bones the later one stays. A part that cannot be put on adds a line to Log and the others are still put on. Then the body triangles the parts on the model lie over are hidden and the data no longer used is deleted. An abort stops between parts; the model is always left valid.

Parameters
AParts
The parts, from one or more libraries, which must stay alive meanwhile.
AOptions
Decide which bones each part covers and what it replaces.
Returns

The number of parts put on.

Public function Remove(const ANodes: TArray<Integer>; const AOptions: TglTFPartOptions): Integer;

Takes parts off the model.

The parts' nodes are deleted with whatever only they used, and the body triangles they covered come back unless another part covers them.

Parameters
