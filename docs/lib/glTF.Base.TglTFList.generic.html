Class TglTFList

Unit

glTF.Base

Declaration

type TglTFList<T:TglTFProperty,constructor> = class(TObjectList<T>)

Description

Owning list of glTF objects, loaded from and saved to a JSON array.

Frees its items. The index of an item is its glTF index, which other objects use to refer to it, so removing or reordering items changes those references.

Methods

Public constructor Create;

Creates an empty list that owns its items.

Public procedure LoadFromJSON(AJSON: TJSONValue; const AJSONPath: string);

Clears the list, then loads one item per element of a JSON array.

Parameters
AJSON
The JSON array; nil or null gives an empty list.
AJSONPath
Location of the array, for example "meshes"; items get "meshes[0]" and so on.
Exceptions raised
EglTFParseError
AJSON is not an array, or an item is invalid.
EglTFMissingPropertyError
An item lacks a required property.
Public function SaveToJSON: TJSONArray;

Returns a JSON array with every item's SaveToJSON.

Returns

A new array, owned by the caller.

Public procedure WriteTo(AJSON: TJSONObject; const AName: string; AAlways: Boolean = False);

Parameters
AJSON
The object to add to; it owns the new array.
AName

AAlways
