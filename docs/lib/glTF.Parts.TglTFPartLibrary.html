Unit

glTF.Parts

Declaration

type TglTFPartLibrary = class(TObject)

Description

The part files loaded and the parts found in them.

Every node with both a mesh and a skin is a part. Load files with LoadFiles, or add documents already loaded with AddDocument. The library owns the documents and the parts.

Public function LoadFiles(const AFileNames: TArray<string>): Integer;

Loads part files and adds the parts found in them.

A file that cannot be loaded adds a line to Log and the others are still loaded. Stops early on an abort.

The .gltf or .glb files.
Returns
