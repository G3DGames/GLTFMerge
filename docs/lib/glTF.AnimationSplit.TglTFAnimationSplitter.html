Unit

glTF.AnimationSplit

Declaration

type TglTFAnimationSplitter = class sealed(TObject)

Description

Finds long animations and splits them by frame ranges.

All methods are class methods. They work on a TglTF whose buffer data is loaded. 

Index := TglTFAnimationSplitter.FindLongAnimation(Doc.Root);
if Index >= 0 then
begin
  Fps := TglTFAnimationSplitter.DetectFrameRate(Doc.Root, Doc.Root.Animations[Index]);
  TglTFAnimationSplitter.Split(Doc.Root, Index, Fps,
    [TglTFAnimationRange.Create('walk', 0, 90),
     TglTFAnimationRange.Create('run', 120, 300)], nil);
end;

Public class function DetectFrameRate(ARoot: TglTF; AAnimation: TglTFAnimation): Double; static;

Estimates the frame rate an animation was made at.

Uses the median gap between two key frames, over all samplers. A result within 1% of a usual rate (12, 15, 23.976, 24, 25, 29.97, 30, 48, 50, 59.94, 60, 120) is snapped to it; otherwise it is rounded to a whole number.

Public class function ValidateRanges(ARoot: TglTF; AIndex, ALastFrame: Integer; const ARanges: TglTFAnimationRanges; out AProblems: TArray<string>): Boolean; static;

Checks the ranges an animation is to be split into.

Each name is required and must be unique, ignoring case, among the ranges and among the model's other animations. Frames must be from 0 to ALastFrame, and EndFrame must be after StartFrame. Gaps and overlaps between ranges are allowed.

Public class function ParseRangeList(const AText: string; out AList: TglTFRangeList): Boolean; static;

Reads animation ranges from a text, such as the list that comes with an animation file.

A line holds a range when it has two whole numbers, the start frame and then the end frame, separated only by spaces, tabs and signs such as "-", "~", ":" or "..", or by the word "to"; a "-" is never a minus sign, as frames are never negative. The name is the text before the numbers or, when there is none, the text after them. It ends at a tab, two spaces, "(", "[", "#", ";" or "//", so notes after it are ignored, and must contain a letter. Quotes are removed, and so are a leading list number such as "3." and surrounding signs such as ":" or ",". Digits inside a name, as in walk_01, are part of it.

Lines before the first range and after the last, such as a title or a note, are ignored. Lines between them that hold text but no range are skipped and listed. The ranges are not checked; see ValidateRanges. 

10 - 40  walk_01           -> walk_01, 10, 40
Look Around    415 - 555  -> Look Around, 415, 555
"Run" 625-685 (3 loops)   -> Run, 625,

Parameters
AText
The text, with any line ends.
AList
What was found.
Returns

True when at least one range was found.

Public class function Split(ARoot: TglTF; AIndex: Integer; AFrameRate: Double; const ARanges: TglTFAnimationRanges; AWarnings: TStrings): Integer; static;

Replaces an animation with one new animation per range.

The new animations take the old one's place in the list, in the order of ARanges, with its Origin and with ExportOnSave True. Their key frame data is appended to the model's buffer in one go, and the data only the old animation used is removed. The ranges are checked first; nothing changes when they are invalid or the data cannot be read.

Parameters
ARoot
The tree to change.
AIndex
Index in ARoot.Animations of the animation to split.
AFrameRate
Frames per second used to turn frames into seconds.
ARanges
The parts, see ValidateRanges.
AWarnings
Receives a line for each clean-up step skipped; may be nil.
Returns

The number of animations created.

Exceptions raised
EglTFError
The ranges are invalid, or the animation's data cannot be read.
