Unit

glTF.Base

Declaration

type EglTFError = class(Exception)

Description

Base class of every exception raised by the glTF reader and writer.

Carries where the problem is: JSONPath always when known, and the line and column in the source text when the document was loaded from text. The location is appended to the message by SetSourceLocation.

Methods

Public procedure SetSourceLocation(const ASourceName: string; ALine, AColumn: Integer; AEndLine: Integer = 0);

Records where the error is in the source text and appends it to the message.

The message gets for example " [model.gltf, line 74, column 13]", or " [lines 72-79]" when AEndLine is after ALine. Only the first call has an effect; a line of 0 or less is ignored. Called by TglTFDocument while loading.

Parameters
ASourceName
File name to show; empty when not loaded from a file.
ALine
1-based line of the start of the problem.
AColumn
1-based column of the start of the problem.
AEndLine
Last line of the offending value, to report a range; 0 for a single position.
