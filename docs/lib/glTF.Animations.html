Description

Imports animations from other .gltf or .glb files into a loaded model.

Animation files are often exported separately from the model they animate, one or several animations per file, sometimes with a copy of the model. Only the animations are taken: each with the samplers it uses, their accessors and bufferViews, and the bytes of those, which are appended to the model's buffer. Meshes, materials, images and the rest of the source file are ignored.

An animation targets nodes by index, and the indices of the source file mean nothing in the model. So each channel's node is matched to a node of the model by name, exactly first and then ignoring case. An unnamed node matches the node with the same index, but only when both files have the same number of nodes. A channel whose node cannot be matched is skipped; an animation with no channel left is not imported.

The import works one animation at a time: each file is loaded, then each of its animations is matched, checked for a duplicate name and added to the model straight away. A duplicate is settled through TglTFAnimationImporter.OnDuplicate. An abort, requested with TglTFAnimationImporter.RequestAbort or answered to a duplicate, stops the import after the animation being added; everything added so far stays and the model is always valid. 

for each file:       load  -> match its nodes
  for each animation: duplicate? -> OnDuplicate -> add to the model
at the end:          remove the data of replaced animations

Progress is reported through TglTFAnimationImporter.OnProgress, so the import can run in a background thread with a progress bar. Use an importer from one thread at a time; only RequestAbort and AbortRequested may be used from another.

TglTFDuplicateAction = (...);

What to do with an imported animation whose name is already used.

Values
  • daReplace: The imported animation replaces the one with the same name, taking its place in the list; the data only the old one used is removed at the end of the import.
  • daKeep: The animation already there is kept and the imported one is ignored.
  • daRename: The imported animation is added under a new, unique name.
  • daAbort: The imported animation is ignored and the import stops; what was added so far stays.
TglTFDuplicateEvent = reference to procedure(AImporter: TglTFAnimationImporter; ACandidate: TglTFAnimationCandidate; AExisting: Integer; var AAction: TglTFDuplicateAction; var ANewName: string);

Asks what to do with an animation whose name the model already uses.

Called on the importing thread, which waits for the answer. A handler that asks the user from a background import must show the question on the main thread and wait for it, for example with a TEvent; it must not be called on the main thread itself then. Reading the model, for example through NameProblem, is safe while the importer waits.
