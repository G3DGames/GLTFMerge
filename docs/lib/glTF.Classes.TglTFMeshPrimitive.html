This item has no description. Showing description inherited from TglTFProperty.ReadChildren.

Loads nested glTF objects, lists and maps; does nothing by default.

Called by LoadFromJSON after the simple values have been read. Free any previously loaded children first, as an object can be loaded more than once.

This item has no description. Showing description inherited from TglTFProperty.Validate.

Checks rules beyond "property X is required"; does nothing by default.

Public constructor Create; override;

Creates the object with the spec's default values.

Indices and Material are GLTF_UNDEFINED_INDEX and Mode is GLTF_MODE_TRIANGLES; Attributes and Targets are empty.
