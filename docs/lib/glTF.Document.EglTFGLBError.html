Unit

glTF.Document

Declaration

type EglTFGLBError = class(EglTFError)

Description

Raised when the GLB container itself is invalid: its header or chunk layout.

Errors in the JSON chunk's content are reported as EglTFParseError or EglTFMissingPropertyError instead, with a line number.
