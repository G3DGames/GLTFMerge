glTF.SourceMap

Declaration

type TglTFSourceMap = class(TObject)

Description

Positions of every value of a JSON text, looked up by JSON path.

The whole text is scanned once, in the constructor. It tolerates malformed JSON: mapping stops where the text stops making sense. Not thread-safe.

Public function TryFind(const AJSONPath: string; out ASpan: TglTFSourceSpan): Boolean;

Finds where a value is in the text.

When the path itself is not in the text, for example a property that is missing, the nearest enclosing value is returned, up to the root.

Parameters
AJSONPath
Path of the value, for example "meshes[0].primitives[2]"; empty for the root.
ASpan
Where the value, or its nearest enclosing value, is.
Returns

False only when not even the root was found.
