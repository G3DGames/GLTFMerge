Unit glTF.SourceMap

Description
Classes, Interfaces, Objects and Records

Description

Maps JSON paths of a glTF text to lines and columns, for error messages.

System.JSON does not keep positions, so TglTFSourceMap scans the original text itself and records where every value is, keyed by the same path syntax as TglTFProperty.JSONPath, for example "accessors[1].count".

TglTFDocument builds a map only when an error has to be reported, so a successful load costs nothing extra.
