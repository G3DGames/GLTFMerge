type TglTFBulkReorienter = class(TObject)

Description

Finds the models in a folder tree and saves re-oriented copies of them.

Call FindModels, then Run, usually from a background thread; read Log and the counts afterwards.

Public class function Problem(const AOptions: TglTFBulkOptions): string; static;

Tells why options cannot be used.

The input folder must exist and the output folder must be given. They must not be the same folder, and the input folder must not be inside the output folder, so no input file can be replaced. The output folder may be inside the input folder: it is then left out of the search. The angles must be from -360 to 360 and the output format GLB or glTF.

Public function FindModels: Integer;

Searches the input folder and its sub-folders for the models to convert.

Folders that cannot be read are skipped and noted in the log. The models are sorted by path, and each gets its output file; two that would share one are told apart. RequestAbort stops the search early, with the models found so far.

Returns

The number of models found; see Items.

Exceptions raised
EArgumentException
The options cannot be used; see Problem.

Public function Run: Integer;

Loads, turns and saves every model found.

Each model is loaded into its own document, saved to its output file with the turn and then freed. A failure is logged and counted, and the next model is done. Stops early, after the model being saved, when RequestAbort was called.

Returns

The number of models saved.

Public procedure RequestAbort;

Asks Run to stop after the model it is on; may be called from any thread.
