type TglTFBuffer = class(TglTFChildOfRootProperty)

Description

A glTF buffer: a block of binary data that bufferViews point into.

The bytes themselves are in Data, filled by TglTFDocument when loading. Where they are stored when saving is decided by TglTFDocument, not by Uri.

Properties

Public property Data: TBytes read FData write FData;

The buffer's bytes; nil when they could not be loaded.

Filled by TglTFDocument when loading, from the GLB BIN chunk, a data URI or an external file, and used when saving. Saving writes byteLength from its length. Not part of the glTF JSON.

Public property SourceFile: string read FSourceFile write FSourceFile;

The file Data was read from; empty for data that was inside the glTF.

Set when the data is loaded from an external file, or from a file found later with TglTFDocument.SupplyResourceFile. Saving copies from it when the buffer must be a separate file and its data is not loaded. Not part of the glTF JSON.
