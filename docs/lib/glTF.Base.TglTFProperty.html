Class TglTFProperty

Unit

glTF.Base

Declaration

type TglTFProperty = class abstract(TObject)

Description

Abstract base of every glTF object, glTFProperty in the schema.

LoadFromJSON runs these steps: (1) the properties marked [glTFRequired] are checked; (2) simple values (numbers, strings, booleans, arrays) are read into the writable properties marked [NeonProperty], directly through RTTI cached per class, as this is done for every object of a file; (3) "extensions", "extras" and any property not in the schema are kept as JSON so they can be queried; (4) ReadChildren loads nested glTF objects; (5) Validate applies rules an attribute cannot express.

SaveToJSON does the reverse from the current property values. Objects are not thread-safe; the per-class metadata is shared and guarded by a monitor.

To add an object type: derive from this class, declare its values as properties with [NeonProperty] and, where required, [glTFRequired]; override ReadChildren and WriteChildren for nested objects, Validate for other rules and glTFTypeName for messages.

Public function SaveToJSON: TJSONObject; virtual;

Builds the JSON for this object from its current property values.

Nothing comes from the JSON the object was loaded from. A simple value is written when it is required or differs from the spec default (the value a new instance has), so values changed in code are written whether or not they were in the original file. Nested objects come from WriteChildren; extensions, extras and non-standard properties are written last.

Returns

A new JSON object, owned by the caller.

Exceptions raised
EglTFError
A value cannot be converted to JSON.
