Unit

glTF.Orient

Declaration

type TglTFReorienter = class sealed(TObject)

Description

Turns a whole model about the X, Y and Z axes.

All methods are class methods. Apply changes the tree it is given, including its buffers' bytes, which it copies first, so arrays shared with another tree are not changed. TglTFDocument uses it on the copy it saves; see TglTFSaveOptions.RotateX. 

// A Z-up model to glTF's Y-up
TglTFReorienter.Apply(Doc.Root, -90, 0, 0, Warnings);

Public class function IsIdentity(AX, AY, AZ: Double): Boolean; static;

Tells whether a turn changes anything.

Parameters
AX
Degrees about the X axis.
AY
Degrees about the Y axis.
AZ
Degrees about the Z axis.
Returns

True when all three are 0, or the turn they make is no turn at all, such as 360 about one axis.

Public class procedure Apply(ARoot: TglTF; AX, AY, AZ: Double; AWarnings: TStrings); static;

Turns the whole model and bakes the turn into its data.

See the unit description for what changes. Does nothing when IsIdentity is True.

Parameters
ARoot
The tree to change; its buffer data must be loaded.
AX
Degrees about the X axis, applied first.
AY
Degrees about the Y axis, applied second.
AZ
Degrees about the Z axis, applied last.
AWarnings
Receives a line for everything that could not be turned exactly; may be nil.
Exceptions raised
EglTFError
Data that must be turned is not loaded.
