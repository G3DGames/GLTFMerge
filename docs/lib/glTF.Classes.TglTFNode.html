Declaration

type TglTFNode = class(TglTFChildOfRootProperty)

Description

A glTF node: an element of the scene hierarchy with a transform.

The local transform is either Matrix or Translation, Rotation and Scale; see HasMatrix.

Protected procedure Validate; override;

This item has no description. Showing description inherited from TglTFProperty.Validate.

Checks rules beyond "property X is required"; does nothing by default.

Called last by LoadFromJSON. For example camera.type "perspective" requires camera.perspective. Raise with RaiseMissing or RaiseInvalid.

Public constructor Create; override;

Creates the object with the spec's default values.

Camera, Skin and Mesh are GLTF_UNDEFINED_INDEX; Matrix is the identity, Rotation [0, 0, 0, 1], Scale [1, 1, 1] and Translation [0, 0, 0].

Public class function glTFTypeName: string; override;

Returns the object's name in the glTF specification.

Returns

Always "node"; used in error messages.

Public function HasMatrix: Boolean;

Tells whether the loaded node gave its transform as a matrix.

Reflects the loaded JSON, not later changes.

Returns

True when "matrix" was present; False when the transform is translation, rotation and scale.
