Declaration

type TglTF = class(TglTFProperty)

Description

The root object of a glTF asset.

Owns every object of the document. Other objects refer to each other by index in these lists, so removing or reordering items changes those references. Usually held by a TglTFDocument.

Protected procedure ReadChildren(AJSON: TJSONObject); override;

This item has no description. Showing description inherited from TglTFProperty.ReadChildren.

Loads nested glTF objects, lists and maps; does nothing by default.

Called by LoadFromJSON after the simple values have been read. Free any previously loaded children first, as an object can be loaded more than once.

Protected procedure WriteChildren(AJSON: TJSONObject); override;

This item has no description. Showing description inherited from TglTFProperty.WriteChildren.

Writes nested glTF objects, lists and maps; does nothing by default.

The counterpart of ReadChildren, called by SaveToJSON after the simple values have been written.

Protected procedure Validate; override;

This item has no description. Showing description inherited from TglTFProperty.Validate.

Checks rules beyond "property X is required"; does nothing by default.

Called last by LoadFromJSON. For example camera.type "perspective" requires camera.perspective. Raise with RaiseMissing or RaiseInvalid.

Creates the object with the spec's default values.
