Unit glTF.AnimationSplit

Description
Classes, Interfaces, Objects and Records
Types

Description

Splits one long animation into several, by frame ranges.

Animation files often hold a single long animation, typically called "Take001", that is really a series of separate moves played one after the other. TglTFAnimationSplitter cuts such an animation into named animations, one per frame range, and replaces it with them. Gaps between the ranges, and before the first or after the last, are simply left out.

glTF stores times in seconds and has no frame rate, so the frame rate is detected from the spacing of the key frames, typically 30 or 24 frames per second, and can be overridden. Frame 0 is time 0 and the last frame is the frame rate times the length of the animation in seconds.

For each range, every channel gets the key frames inside the range, plus a key frame at each end of the range computed from the animation itself: linear interpolation, with spherical interpolation for rotations, the previous value for STEP, and the curve itself for CUBICSPLINE, so each part plays exactly as that stretch of the original did. Times start again at 0 in every new animation. The new key frames are written as floats, whatever the original component type. 

Take001  |--walk--|   |---run---|--jump--|      |
         0       90  120       300      390    450   frames
becomes  walk 0-90, run 120-300, jump 300-390
