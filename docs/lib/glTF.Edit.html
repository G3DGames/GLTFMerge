Unit glTF.Edit

Description
Classes, Interfaces, Objects and Records

Description

Removes objects from a glTF object tree, renumbering every reference to the objects that follow.

glTF objects refer to each other by index, so deleting one means every later index moves down by one. TglTFEdit does that bookkeeping for the references it knows: those in the glTF 2.0 core schema, and the texture and image references of material and texture extensions. It deletes accessors, bufferViews, buffers, animations, nodes, and, through TglTFEdit.DeleteUnusedObjects, meshes, skins, materials, textures, images and samplers. Extensions that keep other indices in their own JSON cannot be renumbered, so the operations that would break them refuse to run when the tree uses one, and say so.

Removing a bufferView also cuts its bytes out of the buffer's Data, so the space is reclaimed. Only bytes no other bufferView uses are cut, always in a multiple of 4 so that the data after it keeps its alignment.

Works on any TglTF, typically the document's own tree or the copy made for a save. Not thread-safe.
