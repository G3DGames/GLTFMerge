type TglTFImage = class(TglTFChildOfRootProperty)

Description

A glTF image: texture data stored in a file, a data URI or a bufferView.

The bytes of the image file are in Data. Whether a save stores them inside the glTF file or as a separate file is decided by Embed.

Public property Embed: Boolean read FEmbed write FEmbed;

Whether a save stores the image inside the glTF file, when the save lets each image decide.

Only used by a save whose ImageSaveMode is ismPerImage; by default the format decides (see TglTFSaveOptions in glTF.Document). True stores it inside the saved file: in the BIN chunk for GLB, in a base64 data-URI buffer for glTF. False writes it as a separate file next to the saved file only; an image that was inside a buffer is taken out of it, so its bytes are not stored twice. Loading sets it to whether the image was already inside the file (a data URI or a bufferView). A save choice, not part of the glTF JSON.

Attributes
NeonIgnore
Public property Shared: Boolean read FShared write FShared;

Whether the image file may be shared with other models when saved as a separate file.

Only used when Embed is False. When True and a file already exists where the image is to be saved, that file is used as it is: it is neither overwritten nor renamed, even if its bytes differ, as other models rely on it. A relative uri that leads outside the output folder, such as "../textures/wood.png", is kept, so that models can share a common texture folder. When False (the default), saving never overwrites a different file: the image gets a unique name instead. A save choice, not part of the glTF JSON.

The file Data was read from; empty for an image that was inside the glTF.

Set when the image is loaded from an external file, or from a file found later with TglTFDocument.SupplyResourceFile. Saving copies from it when the image must be a separate file and its data is not loaded. Not part of the glTF JSON.
