Unit glTFViewer.Orient

Description
Classes, Interfaces, Objects and Records

Description

The Re-Orient tab of the viewer: the turn about X, Y and Z applied when saving.

TglTFOrientFrame holds three angles in degrees, from -360 to 360, decimals allowed. When they turn the model, a save writes it turned, its meshes, nodes, animations and skins re-oriented by TglTFReorienter, so the saved model has the up and forward axes the engine expects without a starting rotation. When all three are 0, the model is saved as it is. The loaded model is never changed, so the angles can be tried and changed freely.

Buttons, one above the other, set common turns: Z-up to glTF's Y-up, the reverse, turning the model to face the other way, flipping it upside down and no turn; each button's Tag picks its angles from a table in the code. The frame is designed in glTFViewer.Orient.fmx; the Bulk Re-Orient dialog shows one too (see glTFViewer.BulkOrient). A graphical way to choose the turn may come later.
