Unit

glTFViewer.Duplicates

Declaration

type TDuplicatePanel = class(TLayout)

Description

Asks, over its parent form, what to do with a duplicate animation.

Create it once with the form as parent; it stays hidden until Ask. Use it on the main thread only.

Public procedure Ask(const AMessage, ASuggestedName: string; const AValidate: TFunc<string, string>; const ADone: TProc<TDuplicateChoice>);

Shows the question; returns at once.

The panel covers the form and takes all input until the user answers. Rename is selected at first, with ASuggestedName in its edit box.

Parameters
AMessage
What clashes with what, shown at the top.
ASuggestedName
A unique name to offer for renaming.
AValidate
Returns why a name cannot be used, or an empty string when it can.
ADone
Called on the main thread with the answer, after the panel is hidden.
Public procedure Cancel;

Answers the question shown with "Abort import", as if the user had pressed it; does nothing when no question is shown.

Used when the form is closed while an import waits for an answer.
