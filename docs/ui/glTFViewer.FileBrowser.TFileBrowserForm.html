Unit

glTFViewer.FileBrowser

Declaration

type TFileBrowserForm = class(TForm)

Description

A file browser for platforms without file dialogs.

Create it with CreateBrowser and show it with ShowModal and a result procedure; it frees itself when it closes. Must be used on the main thread.
