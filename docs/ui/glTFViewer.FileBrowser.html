Unit glTFViewer.FileBrowser

Description
Classes, Interfaces, Objects and Records
Types

Description

The file browser shown on iOS and Android, which have no FireMonkey file dialogs.

TFileBrowserForm lists the folders and files of one folder at a time. Up goes to the parent folder; App files, Documents and Downloads go to those folders and are shown only where they exist. Depending on its TBrowseMode it opens one file, ticks several, asks for a name to save under, or chooses a folder. glTFViewer.Dialogs shows it; use TPlatformDialogs rather than this form.

The form is designed in glTFViewer.FileBrowser.fmx. The name box and the type list are hidden in the modes that do not use them.

TBrowseMode = (...);

What the file browser is for.

Values
  • bmOpen: Open one file: tapping a file chooses it.
  • bmOpenMany: Open several files: tapping a file ticks or unticks it.
  • bmSave: Save: a file name is typed, or taken from a file tapped.
  • bmFolder: Choose the folder shown.
