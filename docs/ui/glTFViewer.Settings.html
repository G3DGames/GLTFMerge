Description

The viewer's settings, kept between sessions in a JSON file where the platform expects application settings.

TglTFSettings holds the folder each file dialog was last used in, under a key per kind of dialog, the folder most recently used by any of them, and named text values for anything else to remember. Every change is written to the file at once, so nothing is lost when the application stops unexpectedly. AppSettings returns the one instance the application uses.

The file is settings.json in a glTFMerge folder: 

Windows:  %APPDATA%\glTFMerge                      (AppData\Roaming)
macOS:    ~/Library/Application Support/glTFMerge
Linux:    $XDG_CONFIG_HOME/glTFMerge, else ~/.config/glTFMerge
iOS:      the app's Library folder
Android:  the app's private files folder

A missing file means no settings yet. A file that cannot be read is renamed to settings.json.bad and the settings start empty. Failing to write the file is not an error: the settings then last for the session only. Use the settings on the main thread only.
