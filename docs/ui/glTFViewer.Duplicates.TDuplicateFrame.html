Unit

glTFViewer.Duplicates

Declaration

type TDuplicateFrame = class(TFrame)

Description

Asks, over its parent form, what to do with a duplicate animation.

Create it once with the form as parent; it covers the form, and stays hidden until Ask. Use it on the main thread only.

Shows the question; returns at once.

The frame covers the form and takes all input until the user answers. Rename is selected at first, with ASuggestedName in its edit box.

Public procedure Cancel;

Answers the question shown with "Abort import", as if the user had pressed it; does nothing when no question is shown.
