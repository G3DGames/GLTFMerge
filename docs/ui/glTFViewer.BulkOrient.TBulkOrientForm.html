Unit

glTFViewer.BulkOrient

Declaration

type TBulkOrientForm = class(TForm)

Description

Asks for the folders, file types and turn of a bulk re-orientation.

Use Execute rather than creating it directly. Must be used on the main thread.

Public class procedure Execute(const ADone: TBulkOrientDoneProc);

Shows the dialog modally, centred on the main form.

It does not block: ADone is called once the user presses "Re-Orient models", and not at all on Cancel. The dialog frees itself.

Parameters
ADone
Called with the options chosen.
