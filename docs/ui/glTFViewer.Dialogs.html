Unit glTFViewer.Dialogs

Description
Classes, Interfaces, Objects and Records

Description

File and confirmation dialogs that work the same way on every FireMonkey platform.

TPlatformDialogs offers open-file (one or several), save-file, select-folder and confirmation dialogs. On Windows, macOS and Linux they are the native dialogs. iOS and Android have no FireMonkey file dialogs, so there a file browser built into this unit is shown instead: it starts in the app's documents folder, which needs no storage permission, and can switch to the shared Documents and Downloads folders where the system allows access.

Every dialog reports its result through a callback rather than a return value, because dialogs do not block on Android. On the desktop the callback runs before the call returns; on mobile it runs later, when the user closes the dialog. Code that follows a dialog must therefore go in the callback. Call these routines on the main thread only. 

Windows, macOS, Linux:  native dialogs
iOS, Android:           built-in file browser
Confirm:                TDialogService on every platform
