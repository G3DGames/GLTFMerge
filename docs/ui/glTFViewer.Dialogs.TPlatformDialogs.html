Unit

glTFViewer.Dialogs

Declaration

type TPlatformDialogs = class sealed(TObject)

Description

Open, save, folder and confirmation dialogs for every FireMonkey platform.

All routines are class methods; use them on the main thread. Results arrive through a callback: immediately on the desktop, after the user closes the dialog on iOS and Android.

Public class function UsesNativeDialogs: Boolean; static;

Tells whether the native dialogs are used.

Returns

True on Windows, macOS and Linux; False on iOS and Android, where the built-in browser is shown.

Public class function DefaultFolder: string; static;

Returns the folder dialogs start in when no other is given.

Returns

The user's documents folder on the desktop; the app's own documents folder on iOS and Android.

Public class procedure OpenFiles(const ATitle: string; const ATypes: TArray<TFileType>; const AInitialDir: string; const ADone: TProc<TArray<string>>); static;

Lets the user choose one or more existing files.

On the desktop, the native dialog with multiple selection. On iOS and Android, tapping a file ticks or unticks it, a tick shown before its name; files can be ticked in several folders before choosing Open.

Parameters
ATitle
Title of the dialog.
ATypes
File types offered; the first is selected.
AInitialDir
Folder to start in; empty or missing uses DefaultFolder on mobile.
ADone
Called with the full paths of the chosen files, in the order they were chosen on mobile; an empty array when cancelled.
