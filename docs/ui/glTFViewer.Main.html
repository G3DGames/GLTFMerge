Unit glTFViewer.Main

Description

Main form of the glTF viewer: open, inspect and save glTF and GLB files.

The Structure tab shows the document as a tree (see glTFViewer.Tree); it is shown at start-up and after every successful load. The Images tab lists every image and whether a mesh uses it; a GLB is saved with its images inside, a glTF with separate image files, unless "Alter image save mode" is ticked there to choose per image (see glTFViewer.Images). The Animations tab lists every animation with its Export choice and imports animations from other files (see glTFViewer.Animations); duplicate names are resolved with glTFViewer.Duplicates. The Parts tab loads body parts and outfit pieces from other files and puts them on the model in place of the parts they replace (see glTFViewer.Parts and glTF.Parts). The Output tab logs loading, saving and the self-tests, and shows errors with their line in the glTF text; it comes to the front when a load fails, when saving and when the self-tests run.

Missing media files are offered for locating after a load and before a save (see glTFViewer.Missing). Self-tests run only when asked for, with the "Run self-tests" button or –selftest.

Loading a model, importing animations, loading part files and putting parts on run in a background thread, with a progress box over the form (see glTFViewer.Progress) showing the model number, model count and stage. The form takes no input meanwhile, from the mouse, touch or the keyboard: the tabs are disabled, and every handler that uses the document checks that no work is running. Closing the form during the work stops an import and closes once the work has finished.

Runs on Windows, macOS, Linux, iOS and Android. File dialogs come from glTFViewer.Dialogs: native on the desktop, a built-in browser on iOS and Android. As dialogs do not block on every platform, opening and saving continue in callbacks. There is no command line on iOS and Android. 

Command line (desktop):  glTFDemo [file.gltf|file.glb] [--selftest]
