Declaration

type TMissingFilesForm = class(TForm)

Description

Modal dialog listing a document's missing media files, with ways to find them.

Use Execute rather than creating it directly. Must be used on the main thread.

Public class procedure Execute(ADoc: TglTFDocument; const AContext: string; const ALog: TProc<string>; const ADone: TProc<Integer> = nil);

Shows the dialog when a document has missing files.

The dialog frees itself when it closes. It does not block: on the desktop and on mobile alike, code that must run after it goes in ADone. When nothing is missing, no dialog is shown and ADone is called at once. Call it on the main thread.

Parameters
ADoc
The document; files found are loaded into its objects.
AContext
First line of the explanation, for example why the dialog is shown now.
ALog
Receives one line for every file found; may be nil.
ADone
Called when the dialog has closed, with how many files are still missing; may be nil.
