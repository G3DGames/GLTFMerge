Unit glTFViewer.Missing

Description
Classes, Interfaces, Objects and Records

Description

Dialog that helps the user find the external media files a glTF document is missing.

TMissingFilesForm lists the buffer and image files that could not be read. "Search folder..." looks for all of them in a folder and its sub-folders; "Locate file..." picks the file for one entry and then looks for the rest in the same folder. Found files are loaded into the document's objects; the uris in the glTF are not changed.

The form is built in code, so the unit needs no .fmx file.
