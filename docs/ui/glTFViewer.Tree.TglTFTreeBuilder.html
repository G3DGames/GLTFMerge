Hierarchy

Unit

glTFViewer.Tree

Declaration

type TglTFTreeBuilder = class(TObject)

Description

Builds the structure tree of a glTF document.

Use the class methods Build and ShowMessage; an instance only lives while a tree is built. Must be used on the main thread.

Public class procedure Build(ATree: TTreeView; ADoc: TglTFDocument);

Clears a tree view and fills it with the structure of a document.

The tree holds only text; it keeps no references to the document's objects, so the document can be freed or reloaded afterwards.
