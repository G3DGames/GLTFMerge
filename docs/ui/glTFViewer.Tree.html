Unit glTFViewer.Tree

Description
Classes, Interfaces, Objects and Records

Description

Fills an FMX tree view with the structure of a glTF document.

Scenes show their full node hierarchy, with meshes, materials, textures and images resolved inline; the default scene is shown in bold and expanded. Materials, textures and images also get their own sections, including which objects use them. Every other top-level array has a section too.

The reader does not yet check that indices point to existing objects, so every reference is range-checked here and shown with a warning sign when it is invalid. A node hierarchy that loops is cut off with a warning instead of recursing for ever.

Every tree item is a styled control, which FireMonkey is slow to create in large numbers, so the long lists are cut off: the Nodes, Accessors and Buffer views sections after 250 entries and each animation after 30 channels, with a line saying how many more there are.
