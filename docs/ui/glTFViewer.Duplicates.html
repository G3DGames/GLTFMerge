Unit glTFViewer.Duplicates

Description
Classes, Interfaces, Objects and Records

Description

Question shown when an imported animation's name is already used.

TDuplicateFrame offers the choices of TglTFDuplicateAction: replace the old animation, keep the old one and ignore the imported one, or rename the imported one, with a unique name suggested and editable. A tick applies the same choice to the remaining duplicates of the import, and "Abort import" stops the import after the animations already added.

It is not a separate modal form but a panel drawn over the main form, like the progress box, so the application keeps running normally while it waits: the import, waiting in its background thread, gets the answer through a callback. The frame is designed in glTFViewer.Duplicates.fmx.
