Unit

glTFViewer.Animations

Declaration

type TglTFAnimationsFrame = class(TFrame)

Description

Frame listing the animations of a document, with an Export checkbox per animation.

Place it on a tab with Align = Client and call Bind after each load and RefreshList after each import. Must be used on the main thread.

Properties

Public property OnImport: TNotifyEvent read FOnImport write FOnImport;

Occurs when the user clicks "Import animations...".

The handler is expected to let the user choose the files, import them and then call RefreshList.

Public property OnClear: TNotifyEvent read FOnClear write FOnClear;

Occurs when the user clicks "Clear animations".

The handler is expected to confirm, remove every animation from the document and then call RefreshList.

Public property OnSplit: TNotifyEvent read FOnSplit write FOnSplit;

Occurs when the user clicks "Split long animation...".

The button is only shown while the document has an animation longer than TglTFAnimationSplitter.LongAnimationSeconds, which is likely to be several animations joined together. The handler is expected to show the split dialog for it and then call RefreshList.

Public property OnChange: TNotifyEvent read FOnChange write FOnChange;

Occurs when the user changes what a save writes: an Export tick.

Public property OnRename: TglTFAnimationRenameEvent read FOnRename write FOnRename;

Occurs after an animation was renamed in the list, after OnChange.
