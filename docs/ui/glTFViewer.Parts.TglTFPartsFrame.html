Unit

glTFViewer.Parts

Declaration

type TglTFPartsFrame = class(TFrame)

Description

Frame listing the parts loaded and the parts on the model.

Place it on a tab with Align = Client, set PartLibrary once, and call Bind after each load and RefreshList after each change. Must be used on the main thread.

Shows the parts on a model.

Public procedure RefreshList;

Rebuilds both lists from the library and the model.

Call it after part files were loaded and after parts were put on or taken off. The ticks of the parts loaded are kept as long as the library has the same number of parts.

Public procedure UntickParts;
