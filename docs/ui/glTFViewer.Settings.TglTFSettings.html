Unit

glTFViewer.Settings

Declaration

type TglTFSettings = class(TObject)

Description

Settings kept in a JSON file between sessions.

Usually reached through AppSettings. The file looks like this: 

 {
   "folders": { "openModel": "C:\\Models", "saveModel": "C:\\Out" },
   "lastFolder": "C:\\Out",
   "values": { "name": "text" }
 }
