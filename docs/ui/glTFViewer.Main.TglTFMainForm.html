Unit

glTFViewer.Main

Declaration

type TglTFMainForm = class(TForm)

Description

The viewer's main window.

Holds one TglTFDocument at a time; a successful load replaces it. Loading a model and importing animations run in a background thread while a progress box blocks the window; everything else, saving included, runs on the main thread.

Public procedure FormCreate(Sender: TObject);

Sets up the menu and the tabs, then loads the file and runs the self-tests given on the command line.

Command line: an optional file name and, with SELF_TESTS, an optional –selftest, -selftest or /selftest, in any order.

Public procedure miSaveAsClick(Sender: TObject);

Asks for a file name and saves the document.

Missing media files are offered for locating first, except the images no mesh shows, which are left out of the save. The dialog suggests GLB; the file type chosen in it decides the extension and format, whatever was typed; replacing an existing file is confirmed. The result, every file written or copied and any warnings are logged.

Parameters
Sender
The control that raised the event.
Public procedure miBulkOrientClick(Sender: TObject);

Shows the Bulk Re-Orient dialog and, when confirmed, turns every model it finds.

The search and the conversion run in the background with the progress box, which can abort after the model being saved; output files that already exist are replaced only after OK. The loaded model is not touched. The result is logged on the Output tab.
