Unit glTFViewer.BulkOrient

Description

The Bulk Re-Orient dialog: the folders, file types and turn for re-orienting every model in a folder tree.

TBulkOrientForm asks for the input folder, which models in it to turn (GLB, glTF or both), the output folder and the format to save as (GLB unless changed), and the turn itself, with the same angles and preset buttons as the Re-Orient tab (a TglTFOrientFrame). "Re-Orient models" is enabled only while every field is valid (see TglTFBulkReorienter.Problem); the reason is shown in red otherwise. Cancel or Escape closes the dialog at any time.

The choices are remembered in the settings file for the next time, and the Browse buttons remember their folders like every file dialog. The dialog only collects the options: the caller does the work, with TglTFBulkReorienter. The form is designed in glTFViewer.BulkOrient.fmx and frees itself.
