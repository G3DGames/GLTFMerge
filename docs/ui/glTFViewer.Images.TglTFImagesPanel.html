Unit

glTFViewer.Images

Declaration

type TglTFImagesPanel = class(TLayout)

Description

Panel listing the images of a document, with an optional list to choose how each one is saved.

Place it on a tab with Align = Client and call Bind after each load. Must be used on the main thread.

Public procedure Bind(ADoc: TglTFDocument);

Shows the images of a document.

"Alter image save mode" is unticked again. The panel keeps a reference to ADoc but does not own it; call Bind(nil) before freeing the document.

Parameters
ADoc
The document to show; nil clears the list.
Public procedure RefreshList;

Rebuilds the rows from the current document.

Call it after the document changes, for example after missing files were located or parts were put on or taken off; the Used column is worked out again. The state of "Alter image save mode" is kept.

Properties

Public property AlterSaveMode: Boolean read GetAlterSaveMode;

Whether "Alter image save mode" is ticked: each image's Embed tick then decides how it is saved, instead of the format.

Public property OnLocateMissing: TNotifyEvent read FOnLocateMissing write FOnLocateMissing;

Occurs when the user clicks "Locate missing...".

The handler is expected to let the user find the files and then call RefreshList.
