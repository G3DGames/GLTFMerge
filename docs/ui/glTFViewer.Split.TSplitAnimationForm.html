Unit

glTFViewer.Split

Declaration

type TSplitAnimationForm = class(TForm)

Description

Lets the user enter the frame ranges a long animation is split into.

Use Execute rather than creating it directly. Must be used on the main thread.

Public class procedure Execute(ARoot: TglTF; AIndex: Integer; const ADone: TSplitDoneProc);

Shows the dialog modally for one animation.

The dialog frees itself when it closes; ADone is only called when the user presses Convert. Nothing is changed by the dialog itself.

Parameters
ARoot
The tree holding the animation; read for its length, its key frames and the names already used.
AIndex
Index in ARoot.Animations of the animation to split.
ADone
Called with the ranges and the frame rate on Convert.
