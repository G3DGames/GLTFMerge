Unit

glTFViewer.Columns

Declaration

type TColumnLayout = class sealed(TObject)

Description

Creates heading and row cells and places them at computed positions.

All methods are class methods. Use them on the main thread. A row is any control that holds cells: the heading layout or a list box item.

Public class procedure LayoutRow(ARow: TControl; const AColumns: TColumnDefs; AFrameWidth, ANarrow, AVeryNarrow: Single); static;

Places the cells of a row in their columns.

The cells go between the row's left and right padding: hidden columns take no room, fixed columns their width in array order, and the column with no width the rest, never less than 40 pixels. Each cell is as tall as the row. Call it when the row is created and whenever its width changes.

Parameters
ARow
The heading row or a list box item.
AColumns
The frame's columns.
AFrameWidth
The frame's width, which decides which columns are hidden.
ANarrow
Below this frame width chNarrow columns are hidden.
AVeryNarrow
Below this frame width chVeryNarrow columns are hidden too.
Public class function AlignHeader(AHeader: TControl; AList: TListBox): Boolean; static;

Sets the heading's padding so its cells sit exactly above those of the rows.

Measures the first row against the heading, so the list box's border and its vertical scroll bar are allowed for. Does nothing while the list is empty. Changes the padding only when it differs, so it can be called whenever the list is painted; lay the heading out again when it returns True.

Parameters
AHeader
The heading, placed above the list box with the same width.
AList
The list box whose rows were filled with the same cells.
Returns

True when the padding was changed.
