Unit glTFViewer.Animations

Description

The Animations tab of the viewer: every animation of a document, with its Export choice.

TglTFAnimationsFrame shows one row per animation with the columns Export, #, Name, From, Channels and Duration. From is "model" for animations that came with the loaded file and the file name for imported ones. The Export column edits TglTFAnimation.ExportOnSave: a save leaves out the animations not ticked, with the data only they used. "Export all" and "Export none" change every flag at once.

Clicking a name edits it in place: Enter keeps the new name, Escape or a name left unchanged keeps the old one, and clicking elsewhere counts as Enter. A name is accepted only when it is not empty and no other animation has it, case ignored (see TglTFEdit.AnimationNameProblem); the text turns red while it cannot be used, and a name not accepted is reported and the old one kept.

"Clear animations" raises TglTFAnimationsFrame.OnClear, to empty the list. "Split long animation..." appears while an animation is over 10 seconds long and raises TglTFAnimationsFrame.OnSplit. "Import animations..." raises TglTFAnimationsFrame.OnImport; the main form shows the file dialog and does the import, then calls RefreshList.

On narrow screens the From column is hidden, and Channels too when narrower still. The frame is designed in glTFViewer.Animations.fmx. The headings and the rows follow the column list in the code and are laid out by glTFViewer.Columns, so the columns line up.
