Unit glTFViewer.Animations

Description
Classes, Interfaces, Objects and Records

Description

The Animations tab of the viewer: every animation of a document, with its Export choice.

TglTFAnimationsPanel shows one row per animation with the columns Export, #, Name, From, Channels and Duration. From is "model" for animations that came with the loaded file and the file name for imported ones. The Export column edits TglTFAnimation.ExportOnSave: a save leaves out the animations not ticked, with the data only they used. "Export all" and "Export none" change every flag at once.

"Clear animations" raises TglTFAnimationsPanel.OnClear, to empty the list. "Import animations..." raises TglTFAnimationsPanel.OnImport; the main form shows the file dialog and does the import, then calls RefreshList.

On narrow screens the From column is hidden, and Channels too when narrower still. The panel is built in code, so the unit needs no .fmx file; headings and rows are laid out by glTFViewer.Columns, so the columns line up.
