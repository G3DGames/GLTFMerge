## Standing rules

These are the user's own rules and override any default behaviour.

**Git**

- Never push. "I will always push manually." Ignore the stop-hook reminders about
  unpushed commits.
- Commit locally. Every commit message ends with the attribution lines given for the
  session (Co-Authored-By and Claude-Session).
- After the user pushes, fetch and verify. If the push differs from the local commits, the
  local version takes precedence until the next push. Changes the IDE made (.dproj, .res)
  are taken from the push.

**Zips**

- Include only the files changed since origin/main, at the zip's root (not inside a
  GLTFMerge folder).
- Never include .git* files, submodules (delphi-neon), the docs/ folder or a patch file.
- Send it as GLTFMerge-changes.zip. The workspace has no rsync, so copy the files with a
  loop over `git diff --name-only --diff-filter=ACMR origin/main HEAD`.

**Documentation**

- GLTFLib (the library): PasDoc `//**` comments only, with no `///` XML anywhere.
- src (the application): both styles on every public item, PasDoc `//**` above XML `///`.
- Implementation sections use plain `//` comments only.

**Code and UI**

- Cross-platform throughout, with asynchronous dialogs (iOS and Android use the built-in
  file browser).
- Saving writes output only from the objects; the loaded model is never changed by a save.
- UI is .fmx files with TFrame containers. The .fmx files were generated by a scratchpad
  generator (designs.py with fmxgen.py); keep .fmx and .pas in step (every component and
  event in the .fmx declared in the .pas).

## How Split works

Each root node of the default scene becomes one model, with all its children. The code is
TglTFModelSplitter in GLTFLib/glTF.ModelSplit.pas.

1. **Find the models.** Roots joined by a skin are grouped together with union-find. Each
   model gets its nodes, meshes, triangle count and world-space bounding box, measured
   from the POSITION accessors' min and max corners.
2. **Name them.** From the root node, made safe for a file name, or model_NNN when the root
   has none. Names are unique whatever their case ("a" after "A" becomes a_1). FreeFileName
   adds _1, _2, … when a file of that name already exists in the output folder.
3. **Decide the origin.** A model keeps its origin when it lies inside its bounding box
   grown by 0.25 × its largest size (NEAR_SHARE). Otherwise it is moved so the centre of
   its box becomes its origin (Recentre).
4. **Decide the scale.** With ScaleUp on (the default), Scale = 1 / the smallest size of
   any model on any axis, when that is under 1. Sizes of 1e-6 × the model's own largest
   size or less are ignored (SIZE_OF_NOTHING), so flat planes don't count.
5. **Cut each model.** From TglTFDocument.CreateCopy. The copy's other skins are released
   first, because DeleteNodes raises for a node that is a skin joint. Then DeleteNodes and
   DeleteUnusedObjects for meshes, skins and materials.
6. **Place it.** Every point P becomes Scale × (P + shift), baked into the roots. A TRS
   root gets T' = s(T + shift) and Scale' = Scale × s. A matrix root gets its 3×3 entries
   × s and its translation s(t + shift). When a root's translation or scale is animated, a
   new parent `<name>_origin` carries T = s · shift and S = s instead.
7. **Save.** Run saves each model as GLB or glTF, with the Re-Orient turn and the EXIF
   choice from SaveOptions, on a background task with progress and abort.

The user's example, icons.glb, holds 100 roots, each rotated X+90 and scaled 0.01, all
sharing one origin with their 10 × 10 grid offsets baked into the vertex data. All 100
are recentred, with a scale of 500, because the icons are 0.002 thick.

## Where things are

- **GLTFLib/** — the library, no UI: glTF.Base, glTF.Classes, glTF.SourceMap,
  glTF.Document, glTF.Edit, glTF.Animations, glTF.AnimationSplit, glTF.Parts,
  glTF.Orient, glTF.Bulk, glTF.Exif and glTF.ModelSplit.
- **src/** — the forms and frames: glTFViewer.Main plus one frame per tab. Main.pas carries
  the self-tests behind `{$DEFINE SELF_TESTS}`.
- **icons/** — the icon for every platform; glTFMerge_1024.png is the master.
  glTFMerge.dproj points there. Windows .ico frames below 256 must be 32-bit BMP, not PNG.
- **tools/** — pasdoc.bat and its dark stylesheets. PasDoc runs with `--staronly`, so only
  `//**` comments are read.

The scratchpad helper scripts of the last session (doc-style checkers, .fmx generator and
checker, a Python port of the split measuring, the icon generator) lived in that session
only; recreate them if needed.
